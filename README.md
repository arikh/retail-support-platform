# Retail Support Platform

A production-grade, multi-agent retail customer-support system built on
LangGraph. A supervisor agent orchestrates specialized workers over a shared,
typed state with durable checkpointing, human-in-the-loop review, and full
observability.

This is a ground-up rebuild of an earlier capstone prototype
(IIT Madras Pravartak). It is not a version bump — it is a distinct system,
architected for reliability, and scale. Design decisions are
recorded as ADRs under `docs/adr/`.

## Status
Early architecture phase. See `docs/adr/` for the decision log.
